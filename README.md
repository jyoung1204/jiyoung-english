# 부리부리영어

GitHub Pages용 영어 학습 PWA. Day 1 자료, 객관식 7/7, 영작 25/30 기록, 문장 저장, JSON 백업과 간격 복습 기능이 있습니다.

GitHub 저장소 Settings → Pages → Deploy from a branch → main / (root) → Save로 공개할 수 있습니다.

주의: 기존 ChatGPT Sites 원본 코드는 확보하지 못했으며 이 앱은 재구현 버전입니다. 현재 아이콘은 독수리 SVG 임시 버전이며 확정된 고해상도 독수리 PNG는 별도로 교체해야 합니다. 자동 Day 2 콘텐츠 동기화는 아직 구현되지 않았습니다.
